# 실용적인 리눅스 작업 재사용의 첫 검증

2026-10-06. 장기 목표는 유지하되 다음 완료 판단은 제한된 리눅스 작업에서
학습과 재사용이 기존 방식에 비해 실제 이득을 주는지로 잡는다.
이 문서는 검증 계획이며 아래 기준의 달성이나 정확도 개선을 보고한 것이 아니다.

## 비교할 경로

동일한 입력과 전체 최종 상태를 세 경로에서 비교한다.

1. 사람이 작성한 일반 프로그램: 실행 정확성과 비용의 기준.
2. 매 요청에 로컬 Gemma를 호출하는 기존 에이전트 경로.
3. 최초 목표 검토와 근거 기반 학습 뒤 계약 ID로 직접 호출하는 텐서 경로.

계약 ID와 인자를 제공하는 호출과 새 자연어 요청의 해석은 별도 측정한다.
직접 호출은 실행 시 LLM·임베딩 모델을 호출하지 않아야 한다.
모든 경로에 같은 입출력과 보존 요구를 적용한다. 작업 전용 Python 절차는
기준 프로그램에만 허용하며 텐서 학습기나 실행 커널에 추가하지 않는다.

## 검증 순서와 통과 조건

### 1. 목표 해석 오류를 드러내기

다음 모델 호출 전에 영어·한국어 평가 요청과 정답을 파일로 고정한다.
복사·이동·보존·삭제, 반대 방향, 부정 표현, 모순, 모호한 경로와
미지원 변환을 포함하고 기존 실패 요청의 재시험과 새 요청을 나눈다.
정답과 채점 결과는 모델 프롬프트나 후보 선택에 제공하지 않는다.

정상 요청의 올바른 초안 수, 잘못된 초안 수, 보류 수를 각각 보고한다.
모순·모호·미지원 요청의 잘못된 초안은 이 평가에서 0건이어야 한다.
항상 보류하는 방식은 개선으로 채택하지 않는다. 같은 새 요청에서 기존
기본 경로보다 정상 요청 처리율을 떨어뜨리지 않고 오류를 줄여야 한다.
통과해도 자동 승인이나 범용 의미 정확성을 주장하지 않는다.

### 2. 계약 호출과 전체 상태를 검증하기

학습·검증·미사용 입력을 분리한다. 빈 데이터, 바이너리, 긴 내용,
유니코드 경로, 기존 목적 파일, 보존할 추가 파일·빈 폴더를 포함한다.
저장과 재로드 뒤 전체 파일 내용·디렉터리 상태와 반환값을 검사한다.
불필요한 변경 한 건도 성공으로 계산하지 않는다.

경로 역할은 먼저 호출자 제공 입력으로 검증한다. 자연어에서 경로를
추출하는 능력을 이 결과에 합산하지 않는다. 실제 실패 뒤 부분 변경을
원상 복구할 수 있다고 가정하지 않고 실패 상태를 별도로 기록한다.

### 3. 반복 실행의 비용을 비교하기

초기 해석·근거 수집·학습·저장·모델 로딩 비용과 반복 실행 비용을 분리한다.
한 번의 실행, 10회, 100회 반복의 총 비용과 호출당 중앙값·95백분위 시간을
같은 환경에서 보고한다. 워밍업과 측정 순서를 기록하고 독립 반복을 수행한다.
실패·재시도·질문 비용도 포함한다. 더 빠른 오답은 이득으로 계산하지 않는다.

LLM 호출 횟수와 토큰, 벽시계 시간, 측정 가능한 메모리를 기록한다.
같은 결과의 일반 프로그램보다 빠르다고 가정하지 않는다. 최초 학습 비용을
포함한 손익분기 반복 횟수를 계산할 수 없다면 그 이유를 명시한다.
로컬 모델의 토큰 수를 근거 없이 금전 비용으로 환산하지 않는다.

### 4. 새로운 복합 작업으로 확장하기

앞의 경로가 검증된 뒤 파일 목록·조건·집계 또는 프로세스 입출력을 조합한
새 작업으로 확장한다. 목표와 예제에서 절차를 찾아야 하며 사람이 작성한
작업 순서를 런타임에 숨겨 넣지 않는다. 탐색 시간·후보 수·실패도 보고한다.

## 실행 환경과 현재 위치

2026-10-06 사용자의 최신 지시로 Windows의 기존 nerdctl `vectorpro-test`
하나와 설치된 로컬 Gemma만 사용한다. 이전 Docker 환경 계획을 대체한다.
모델·컨테이너 추가 생성이나 이미지 빌드 없이 기존 환경을 재사용한다.
기존 프로젝트 마운트와 Gemma 3 1B Q8_0 GGUF를 확인했다. Docker 연결 실패는
현재 Rancher Desktop이 containerd 엔진을 사용하기 때문이었다.
이전 Mac의 Gemma 12B 결과와 현재 1B 결과를 동일 모델의 비교로 합산하지 않는다.

환경 연결 직후의 작은 진단은 다음 명령으로 실행한다. 출력 경로가 이미 있으면
거절하며 원시 프롬프트·응답과 비용을 보존한다. 여섯 요청은 작성자가 고정한
소규모 진단이며 독립 정확도 평가나 실행 성공 증명이 아니다. 초안을 실행하지 않는다.

```powershell
nerdctl exec -e PYTHONPATH=/workspace/src -e OMP_NUM_THREADS=1 -e MKL_NUM_THREADS=1 vectorpro-test python -m experiments.local_goal_safety --output results/local_goal_safety_windows_20261006
```

현재는 제한된 절차 획득·저장·직접 실행과 선택적 목표 해석이 구현된 단계다.
다음 작업은 모순 요구 누락과 경로 역할의 검증, 이후 반복 비용 비교다.
리눅스 전체 범위와 범용 언어 대체는 이 평가의 통과만으로 완료되지 않는다.
