# 목록·문자열·JSON과 학습된 순회

리눅스 사용 로드맵의 데이터 처리 기반을 추가했다. 새로운 실행 의미는 호스트가
제공하지만, 작업별 호출 순서·인자 경로·반복 본문은 예제에서 탐색해 텐서에 저장한다.
실행 커널에 작업 이름별 분기를 넣지 않았으며 기존 저장 형식과 기본 6개 primitive를 유지한다.

## 제공되는 실행 의미

| 연산 | 입력 | 출력 |
|---|---|---|
| `list.length` | NUL 목록 버퍼 | 항목 수 |
| `list.get` | 목록, 0부터 시작하는 인덱스 | 해당 항목 버퍼 |
| `list.append` | 목록, 항목 버퍼 | 항목을 추가한 새 목록 버퍼 |
| `path.join` | 부모 경로, UTF-8 자식 버퍼 | 정규화한 상대 경로 |
| `text.concat` | UTF-8 버퍼 두 개 | 연결한 새 UTF-8 버퍼 |
| `json.get` | JSON 버퍼, UTF-8 키/배열 인덱스 버퍼 | 해당 값의 JSON 버퍼 |
| `json.text` | JSON 문자열 버퍼 | 문자열의 UTF-8 버퍼 |

목록은 각 항목이 NUL로 끝나는 바이트 형식으로 `directory.list`와 바로 연결된다.
빈 버퍼는 0개, `00`은 빈 항목 1개다. 항목 안의 NUL은 허용하지 않는다.
UTF-8 문자열 연산은 잘못된 인코딩을 거절한다. JSON은 중복 필드/NaN/Infinity를
거절하며 `json.text`는 문자열만 받는다. 모든 새 버퍼는 기존 바이트 한도와 핸들 폭을 따른다.
여러 반환값과 동적 객체 타입을 구현한 것은 아니다. 구조화된 값은 아직 JSON 바이트다.

학습 예제의 입력 타입에 `buffer`를 추가했다. 해당 입력은 hex 문자열이며 호출 계약의
버퍼 입력과 같다. 파일·디렉터리 상태는 여전히 전체 스냅샷으로 검증한다.
계약 학습은 `allowed_operations`의 호스트 작업과 그 범위를 벗어나지 않는 기존
절차를 후보에 사용한다. 숫자 연산은 재사용한다. 채택 후에도 전체 의존 작업을 확인한다.

## 목록 순회 문법

`state_lesson.list_loops: true`는 명시적인 역순 반복 문법을 활성화한다.
목록의 개수에서 시작해 학습된 숫자 연산 중 감소 연산을 행동 검사로 찾고,
인덱스를 줄인 뒤 항목을 추출한다. 0개면 본문을 실행하지 않는다.

본문은 타입에 맞는 호출과 인자 연결을 탐색한다. 현재 문법은 마지막에 하나의
숫자 반환/효과 호출을 두고, 그 인자를 만드는 경로·버퍼 표현식 DAG를 찾는 형태다.
중간 호출은 경로/버퍼를 반환해야 하고 모든 중간 결과가 마지막 호출에 연결돼야 한다.
임의의 본문 블록, 조건부 항목 선택, 여러 효과 호출, 중첩 순회는 아직 검색하지 않는다.
이 제한은 탐색 문법의 경계이며 채택된 프로그램의 호출 효과를 생략하는 최적화가 아니다.
후보 수를 제한하고 단조 시간 한도는 본문 생성 중에도 확인한다. 실패한 후보는 등록하지 않는다.

검증된 `batch_copy`는 목록 조회·길이·감소·항목 추출·경로 결합·읽기·쓰기를
8개의 호출/10개의 제어 단계를 가진 텐서로 저장한다. 폴더별 파일 경로와 복사 순서는
호스트의 작업 전용 Python 함수로 실행하지 않는다. 본문과 전달 경로를 탐색했다.
결과 숫자는 마지막으로 수행한 쓰기 길이이고, 빈 목록은 0이다. 총 파일 수/총 바이트
집계를 학습했다는 뜻은 아니다. 목적 폴더는 먼저 존재해야 하며 원본은 직계 파일만 지원한다.

`save_field`는 JSON 필드 조회 → 문자열 해석 → 파일 쓰기의 3단계 절차를 탐색한다.
기존 산술·파일 기능과 새 기능을 같은 텐서 파일에 축적하고 계약 ID로 호출한다.

## 재현과 결과

```powershell
nerdctl exec -e OMP_NUM_THREADS=1 -e MKL_NUM_THREADS=1 vectorpro-test python -m pytest -q tests/test_structured_data.py
nerdctl exec -e OMP_NUM_THREADS=1 -e MKL_NUM_THREADS=1 vectorpro-test python experiments/structured_data.py --output results/structured_data_replay
nerdctl exec -e OMP_NUM_THREADS=1 -e MKL_NUM_THREADS=1 vectorpro-test python -m pytest -q
```

결과는 기존 디렉터리를 덮어쓰지 않는다. `results/structured_data_verified`에 사전
커리큘럼, 저장된 `program.pt`, 전체 호출 및 파일/디렉터리 스냅샷을 보존했다.
프로그램 SHA-256은 `4c55808398c4e5b031ab1019c184d70c3fd18c79b9260e36597151f1dc7abe81`이다.
학습용/검증용 각 2개 사례와 별도 native 루트 4개를 구분했다.
미사용 목록 0·1·7·17개 및 새 JSON 키 `message`를 재학습 없이 처리해 **4/4 통과**했다.
관련 검증 27 passed, 7.87초. 최종 전체 회귀 **251 passed, 200.58초**.
목록 절차는 462개, 누적 라이브러리의 JSON 절차는 11868개 후보를 평가한 뒤 채택됐다.
한글·줄바꿈 이름, 빈 파일, 바이너리를 포함해 확인했다. LLM/검색 인코더를 import하지 않았다.

기능 누적으로 JSON 학습이 5000 후보 한도에서 실패한 두 예비 실험도 보존했다.
최종 통합 실험은 허용 작업 필터와 최대 20000 후보 한도 안에서 성공했다.
예제는 탐색 중 수정하지 않았다. 후보 탐색의 확장 비용은 여전히 남은 과제다.

현재 위치는 파일시스템 기반에서 목록 순회와 구조화 데이터 추출을 연결한 단계다.
제한된 항목 조건 선택·산술 집계는 아래 검증까지 진행했다. 다음은 다중 결과 처리,
이어서 프로세스·표준 입출력·파이프다.
네트워크, 독립 목표 검증 및 정확성을 유지한 경로 최적화도 남아 있다.
native 실행 중 실패가 발생하면 앞서 실행한 파일 변경을 되돌리지 않는다.

## 조건 선택과 학습 산술 집계

`list_loops`와 `control_flow`를 함께 켜면 항목 및 입력 버퍼로 만드는 값 판정과
참/거짓 분기를 탐색한다. `text.ends_with(buffer, buffer)`는 제공된 UTF-8 호스트
의미이며, 작업에 사용할 판정·극성·본문·인자 경로는 전체 상태 예제에서 선택한다.
`list_reduction: true`는 학습된 이항 산술로 누산기를 갱신한다. 감소와 덧셈은
학습 기능이며 파일 크기 합산 순서를 Python 실행기에 내장하지 않았다.
0개 목록의 출력은 0이며, 조건에 맞는 빈 파일 쓰기도 실행한다.

목록 생산자를 먼저 탐색하고, 일반 명령 시뮬레이션으로 학습 사례의 불일치 후보를
새 MemoryHostContext에서 제거한다. 살아남은 후보는 실제 제어 텐서로 컴파일해
학습·검증 사례를 다시 실행한다. 검증 사례는 사전 제거에 사용하지 않는다.
최대 호출 12개, 후보 20000개, 시간 60초 제한은 유지한다.

`experiments/list_selection.py`의 사전 커리큘럼과 산술 예제를 사용했다.
선택 복사: 1404후보/9호출/13텐서 단계. 합산: 17후보/8호출/11텐서 단계.
별도 native 루트의 목록 0·1·7·17개에서 저장·재로딩 후 **4/4** 통과했다.
관련 10개 테스트와 전체 회귀 261개 통과(각 12.20초, 214.27초).
전체 파일·디렉터리 상태와 합산 결과를 확인했고 LLM 없이 직접 계약을 호출했다.
자료는 `results/list_selection_verified/{curriculum.json,program.pt,summary.json}`이다.

```powershell
nerdctl exec -e OMP_NUM_THREADS=1 -e MKL_NUM_THREADS=1 vectorpro-test python -m pytest -q tests/test_list_selection.py
nerdctl exec -e OMP_NUM_THREADS=1 -e MKL_NUM_THREADS=1 vectorpro-test python experiments/list_selection.py --output results/list_selection_replay
```

이 문법은 단일 판정, 타입에 맞는 표현식 본문과 단일 값 누산기에 한정된다.
누산 결과는 W비트이며 넘침은 모듈러 연산이다. 중첩 조건, 여러 결과를 반환하는
레코드, 재귀 디렉터리, 일반 자료구조의 학습을 증명하지 않는다.
